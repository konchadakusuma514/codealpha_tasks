# 📚 Book Analytics Dashboard using Web Scraping

## 📌 Project Description

This project was developed as part of the **CodeAlpha Python Programming Internship**.

It scrapes book information from the "Books to Scrape" website using **BeautifulSoup**, stores the data in a CSV file, performs analysis using **Pandas**, generates visualizations with **Matplotlib**, and displays the data through a **Flask web application**.

---

## 🚀 Features

- Web Scraping using BeautifulSoup
- Extracts 1000 books from 50 pages
- Stores data into CSV
- Data Cleaning
- Data Analysis
- Search Books
- Filter Books by Rating
- Sort Books by Price
- Flask Web Dashboard
- Bootstrap Responsive UI
- Data Visualization

## ▶️ Installation

```bash
pip install -r requirements.txt
```

Run scraper:

```bash
python scraping.py
```

Run Flask:

```bash
python app.py
```

Open:

```
http://127.0.0.1:5000
```
